{# KnowledgeTableOfContents — sticky right-side "On this page" nav. Two elements make up the active-item indicator, sitting side-by- side inside `.__toc-body`: 1. `.__toc-rail` — a static 1px gray vertical column running the full height of the TOC. Purely decorative (aria-hidden) and pointer-events: none so it never intercepts clicks. It's just a positioned div with a background color; no SVG, no diagonal segments, no depth-aware routing — the same rail shape whether the doc has 3 headings or 30, at every nesting level. 2. `.__toc-active-indicator` — a 2px blue block layered on top of the rail (also inside `.__toc-body` but visually stacked over the gray column). `scripts/knowledge_agent.js` measures the active TOC link's `getBoundingClientRect` relative to the body and sets `transform: translateY(px)` + `height: px` on this element so the block highlights exactly the current section's row. Because we only ever move it vertically, the block STAYS straight — no diagonals, no ballooning across multiple items, just a single row height per active section. The `
    ` link list sits to the right of the rail. Heading depth is signalled through per-anchor `padding-left` (16px for h2, 28px for h3) so the labels indent but the gray rail stays flush at x=0 for every level. Populated by JS on load + every Preview render. Sub-list nesting is preserved for accessible position-in-list semantics. #}
