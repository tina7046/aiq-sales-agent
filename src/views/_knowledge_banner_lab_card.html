{# The art, inlined rather than referenced by an . Inlining is the awkward embed and it's chosen on purpose: the asset is an animated SVG that loops forever, and behind an it loops straight through `prefers-reduced-motion: reduce`. The file does carry a rule for that case, but an image is its own document and never learns what this page was asked for. Inlined, its stylesheet is part of this document and the rule fires — measured both ways. An inline SVG brings its 29 ids into the document, so two copies on one page need `key` to tell them apart — it's passed through to `inlineSvg`, which renames the ids and every reference to them. The lab renders this macro twice and passes a different key each time. The inner div is the sizing box: the file deliberately ships with a viewBox and no width/height, so it takes whatever box it's given and keeps its own ratio, which is now 1:1. Don't reach for `object-fit: cover` to close a gap — it crops the wand's travel at both ends, which is the subject. This is the BARE cut of the artwork, the one with no ground drawn into it. The full `Iso_Scan.svg` carries its own isometric grid, which would sit at the scene's own fixed scale and land on top of the banner's backdrop at a different cell size. One grid, from the CSS, so it spans whatever the layout gives it. `role`/`aria-label` are injected onto the root tag at build time rather than written into the file, which is generated and would lose them on the next rebuild. #}
