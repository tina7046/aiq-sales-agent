{# Knowledge banner LAB ===================================================================== Standalone sandbox for redesigning the promo banner at the top of the Knowledge page — its layout, its copy, and the dismiss gesture that fades it out while the rest of the column glides up. Reachable at /knowledge_banner_lab.html. Nothing links to it and nothing in the app imports from it, so anything tried here is invisible to the demo until it's deliberately ported. Isolation is the point, and it's the same arrangement the cadence and prospect table labs use. Every file here is a COPY of its production counterpart carrying the same class names, hooks and tokens: src/views/_knowledge_banner_lab_card.html ← the banner block in knowledge.html src/styles/knowledge_banner_lab.scss ← home.scss, the "Knowledge banner" section plus the motion tokens declared on .seller-home__knowledge-body-inner src/scripts/knowledge_banner_lab.js ← home.js, the four dismiss functions src/views/data/knowledge_banner_lab.json ← knowledge.json's `banner` object So a tweak lands on the same selector, in the same block, in the same place it would in the real file — porting is a copy of the changed lines rather than a translation of an override. The page deliberately does NOT load home.css: the copies use production class names, so loading both would make which rule wins depend on link order. What the page gives you that the Knowledge page doesn't ------------------------------------------------------- The dismiss, on a loop and with its clock exposed. In the app the gesture is a one-way door — "Got it" hides the banner for the rest of the session, and the only way back is the Home tab, which is a full page load. Here Replay puts it back untouched, so the same gesture can be watched twenty times in a row. The four numbers behind it are sliders. They're the custom properties the copied CSS and the copied script both read off the DOM (--knowledge-banner-fade / -settle / -glide-delay / -ease), written live onto the column, so a value can be judged by eye before it's written back into home.scss. Nothing in the component knows the toolbar exists. The glide is the reason for the filler rows and the fixed-height scroll area below. Half the gesture is everything under the banner moving up into its space; on a page where the banner is the only thing there, that half is invisible. What it doesn't have: the preload script. On the real page a small inline script hides the banner during parse if it was dismissed earlier in the session, so it can't flash. The lab doesn't persist dismissal — that's the one edit inside the copied functions — so there's nothing for it to read. To port a change back into the app, diff the lab copy against its source.
