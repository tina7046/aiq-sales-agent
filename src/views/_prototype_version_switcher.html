{# Prototype-only design-version switcher ===================================================================== Fixed bottom-right control for hopping between the design versions of the Skills landing (/skills.html ↔ /skills-v2.html). Included by both version bodies and by nothing else. SCAFFOLDING, NOT PRODUCT UI. It exists to make two designs comparable in a review, and it is meant to be deleted along with the `prototypeVersions` block in skills.json once a direction is chosen. Deliberately kept off every other page: no other surface includes this partial, and nothing global references it. Two plain anchors, no JavaScript. A real page load per switch is the point — each version is a separately-rendered document, so a client-side swap would have to rebuild the whole body and re-run `bindSkills()`, trading a small partial for a controller that could drift from the templates. Full navigation also means the browser's back button, bookmarks, and hard-refresh all behave, and the current version is legible in the address bar during a screen share. Context expected from the includer: skillsData — the parsed skills.json (for `prototypeVersions`). skillsVersion — this page's own version id (`v1` / `v2`), set by the page template.
